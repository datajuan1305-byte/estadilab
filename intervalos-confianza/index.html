Intervalos de confianza: estimar con un margen de error

¿Qué es un intervalo de confianza?

Una muestra da una estimación puntual (por ejemplo, un promedio de 52), pero el valor real de la población es desconocido. El intervalo de confianza entrega un rango de valores plausibles para el parámetro, construido con un método que, repetido muchas veces, captura el valor verdadero en el nivel de confianza indicado (90 %, 95 % o 99 %).

Interpretación correcta

Con 95 % de confianza no se afirma que hay 95 % de probabilidad de que el parámetro esté en este intervalo específico: el parámetro es fijo, lo aleatorio es el intervalo. Lo correcto es decir que el método produce intervalos que contienen el valor real en el 95 % de las repeticiones.

Qué hace más ancho o más angosto un intervalo

  • Mayor confianza → intervalo más ancho.
  • Mayor tamaño de muestra → intervalo más angosto.
  • Mayor variabilidad de los datos → intervalo más ancho.

Tipos incluidos

La herramienta calcula intervalos para la media con σ conocida (Z) y desconocida (t de Student), para proporciones, para la varianza (ji-cuadrado, asimétrico) y el tamaño de muestra necesario para lograr un margen de error dado.

Ejemplo resuelto

En una muestra de n = 25 se obtiene media 50 y desviación estándar 10. Con σ desconocida se usa t con 24 grados de libertad: t = 2,064 para 95 %. El margen de error es 2,064 × 10/√25 = 4,13, por lo que el intervalo de confianza del 95 % es (45,87; 54,13). Si quisieras un margen de error de 2 con la misma variabilidad, necesitarías aproximadamente n = (1,96 × 10/2)² ≈ 97 observaciones.

Errores frecuentes y buenas prácticas

  • Interpretación. Un intervalo del 95 % no significa que haya 95 % de probabilidad de que el parámetro esté en ese intervalo concreto; significa que el procedimiento captura el valor verdadero en el 95 % de las muestras.
  • Elegir el intervalo correcto. Para medias con σ desconocida, use t; para proporciones, verifique el tamaño de muestra o use métodos alternativos si es pequeño.
  • Muestra no aleatoria. Ningún intervalo corrige un muestreo sesgado.
  • Planeación. Si necesita un margen de error determinado, calcule el tamaño de muestra antes de recolectar los datos.

Preguntas frecuentes

¿Z o t?

Si conoces la desviación estándar poblacional, usa Z. Si solo tienes la de la muestra (lo habitual), usa t de Student.

¿Qué nivel de confianza elijo?

95 % es el estándar. Sube a 99 % si el error es costoso; baja a 90 % si aceptas más riesgo a cambio de un intervalo más angosto.

¿Por qué el intervalo de la varianza no es simétrico?

Porque se basa en la distribución ji-cuadrado, que es asimétrica.

¿Cuántos datos necesito para un margen de error dado?

Usa el módulo de tamaño de muestra: depende del margen deseado, la confianza y la variabilidad esperada.
